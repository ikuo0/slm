### 1. [`build_model`](file:///workspaces/slm/impl_gen3/src/libs/nn_trainer/nn_trainer/__init__.py#L106-L147) の各層の役割

```
Input(語彙数 V)
  ↓
[隠れ層ブロック × 2回 (デフォルト 256 → 256)]
  ├─ Dense(256, activation="gelu")  : 全結合層＋活性化関数
  ├─ LayerNormalization             : 値の偏り・発散を抑えて学習を安定化
  └─ Dropout(0.1)                   : 10%のニューロンをランダムに無効化（丸暗記＝過学習の防止）
  ↓
Dense(語彙数 V, activation="softmax"): 出力層（全単語の出現確率 0.0〜1.0、合計 1.0 に変換）
```

| コード箇所 | 要素名 | 役割（ひとことで言うと） |
| :--- | :--- | :--- |
| [`tf.keras.Input(shape=(vocab_size,))`](file:///workspaces/slm/impl_gen3/src/libs/nn_trainer/nn_trainer/__init__.py#L121) | **入力層 (`Input`)** | 32単語分の「重み付きOne-Hotベクトル（長さ＝語彙数 $V$）」を受け取る入口です。 |
| [`layers.Dense(units, activation="gelu")`](file:///workspaces/slm/impl_gen3/src/libs/nn_trainer/nn_trainer/__init__.py#L124-L128) | **全結合層 (`Dense`) ＋ 活性化関数 (`GELU`)** | 入力のすべての要素に重みを掛けて足し合わせ（線形変換）、256個の特徴に圧縮・変換します。`gelu`（または `relu`）は「複雑なパターンを表現するための非線形関数」です。 |
| [`layers.LayerNormalization()`](file:///workspaces/slm/impl_gen3/src/libs/nn_trainer/nn_trainer/__init__.py#L129) | **レイヤー正規化 (`LayerNormalization`)** | 層を通過するごとに数値が大きくなりすぎたり偏ったりするのを防ぐため、平均0・分散1付近に整えて学習を速く・安定させます。 |
| [`layers.Dropout(0.1)`](file:///workspaces/slm/impl_gen3/src/libs/nn_trainer/nn_trainer/__init__.py#L130-L131) | **ドロップアウト (`Dropout`)** | 学習時に毎回ランダムに10%の繋がりを切って学習させます。特定のパターンへの丸暗記（過学習）を防ぎます。 |
| [`layers.Dense(vocab_size, activation="softmax")`](file:///workspaces/slm/impl_gen3/src/libs/nn_trainer/nn_trainer/__init__.py#L133-L137) | **出力層 (`Dense` + `softmax`)** | 256個の特徴から「次の単語候補（語彙数 $V$ 個）」それぞれのスコアを出し、`softmax` で **全単語の確率（合計すると 1.0＝100% になる分布）** に変換します。 |
| [`Adam` / `SparseCategoricalCrossentropy`](file:///workspaces/slm/impl_gen3/src/libs/nn_trainer/nn_trainer/__init__.py#L140-L145) | **最適化 (`Adam`) と 損失関数 (`Crossentropy`)** | 「正解の単語IDの確率がどれだけ低かったか（ズレ＝Loss）」を `SparseCategoricalCrossentropy` で測り、ズレが小さくなるように `Adam` が各層の重みを少しずつ更新します。 |
